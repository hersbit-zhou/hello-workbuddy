## 已知网络问题

本机所在网络对 github.com 的 443 端口是间歇性可达的，因此在
`C:\Windows\System32\drivers\etc\hosts` 中把 github.com 固定到了一个可用节点。
该节点失效时，网页会打不开，需要改这一行。
